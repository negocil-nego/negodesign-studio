Como exemplo tens comuns para os campo de inputs:

1. Dados Pessoais e Identificação
   Nome / Sobrenome:
   "Ex: João Silva" / "Insira o seu nome completo"
   E-mail:
   "seu.email@exemplo.com" / "nome@dominio.com"
   Telefone / Celular:
   "(+244) 9XX XXX XXX" / "(00) 90000-0000" / "Digite apenas números"
   Documentos de Identificação (BI / CPF / Passaporte):
   "000000000XX000" / "Apenas números ou letras conforme a identidade"
2. Autenticação e Segurança
   Palavra-passe / Senha:
   "Mínimo de 8 caracteres" / "Crie uma palavra-passe forte"
   Confirmar Palavra-passe:
   "Repita a palavra-passe"
   Código de Verificação / OTP:
   "Digite o código de 6 dígitos" / "000000"
3. Localização e Endereço
   Endereço / Rúa:
   "Rua, Bairro, Nº da casa" / "Pesquisar endereço..."
   Código Postal / CEP:
   "0000-000"
   Cidade / Província / Estado:
   "Selecione a sua localização"
4. Pesquisa e Filtros
   Barra de Pesquisa:
   "Pesquisar..." / "Buscar por nome, categoria ou código..." / "O que você procura hoje?"
5. Pagamentos e Finanças
   Número do Cartão:
   "0000 0000 0000 0000"
   Validade do Cartão:
   "MM/AA" ou "MM/AAAA"
   Código de Segurança (CVV/CVC):
   "123" ou "Os 3 dígitos no verso do cartão"
   Valor / Quantia:
   "0,00" / "Insira o montante"
6. Mensagens e Comentários (Textareas)
   Caixa de Texto Aberta:
   "Escreva a sua mensagem aqui..." / "Descreva o seu problema em poucas palavras..." / "Deixe um comentário..."
