# AdminCrud (`admin-crud`)

Página administrativa completa de CRUD que integra:
- `Sidebar` (navegação lateral das tabelas/módulos)
- `Menu` (barra superior de navegação)
- `DataTable` (tabela paginada com suporte a `DataTextProps`, células `badge` e coluna `dropdown` de acções)
- `ModalForm` (modal com formulário dinâmico para criação e edição de registos)

Disponível em **Svelte**, **React**, **Vue** e **Flutter**.
