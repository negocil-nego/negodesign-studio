# NegoDesign Bootstrap-Compatible `@layer components` CSS

Separated Tailwind CSS `@layer components` stylesheets mapped to standard Bootstrap 5 / Bootswatch class names.
All files are imported via `bootswatch.css` and automatically copied when exporting any Web component.

## Files
- `button.css`, `badge.css`, `input.css`, `form.css`, `select.css`, `card.css`, `table.css`, `menu.css`, `sidebar.css`, `modal.css`, `accordion.css`, `carousel.css`, `nav.css`, `alert.css`, `progress.css`, `list-group.css`, `container.css`
- `themes/themes-a-m.css` & `themes/themes-n-z.css`: All 26 Bootswatch v5.3.8 theme variable palettes.
