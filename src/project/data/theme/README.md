# NegoDesign Theme Architecture (`ts` & `dart`)

- **`ts/`**: TypeScript design tokens, `StyleComponent` definitions, and all 26 Bootswatch themes (`bootswatch_part1.ts` .. `bootswatch_part7.ts`, `bootswatch.themes.ts`).
- **`dart/`**: Flutter `NegoThemeData` and `NegoBootswatchPalette` classes for all 26 Bootswatch themes (`bootswatch_part1.dart` .. `bootswatch_part7.dart`, `theme_data.dart`).
